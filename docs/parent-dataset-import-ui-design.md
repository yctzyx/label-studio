## 3. 线框图

### 3.1 顶栏（桌面宽度足够时一行）

```text
┌──────────────────────────────────────────────────────────────────────────────┐
│ [ URL 输入…………………………… ] [添加URL]   或   [↑ 上传文件]   或   [📂 从父平台选择数据集] │
└──────────────────────────────────────────────────────────────────────────────┘
```

窄屏时：**第三按钮与「上传文件」同一行或换行**，保持「或」分隔可读性（与现有 `import.or` 一致）。

### 3.2 点击「从父平台选择数据集」→ 全屏或居中 **Modal / Drawer**

推荐 **Modal（宽度 `min(720px, 92vw)`）**，标题与底部按钮固定，中间可滚动。

```text
┌─────────────────────────────────────────────────────────────┐
│  选择父平台数据集                                      [×]   │
├─────────────────────────────────────────────────────────────┤
│  数据源  [ 全部 ▾ ]  （可选：仅 S3/MinIO 类型）              │
│  搜索    [ 数据集名称……………………………………… ]   [ 查询 ]          │
├─────────────────────────────────────────────────────────────┤
│  数据集名称        │ 数据源      │ 路径前缀    │ 操作      │
│────────────────────│─────────────│─────────────│──────────│
│  反欺诈图片数据集   │ TDSC / 78   │ /anti_fraud…│ [ 选择 ]  │
│  人脸关键点…       │ TDSC / 78   │ /face       │ [ 选择 ]  │
│  …                 │ …           │ …           │ …        │
├─────────────────────────────────────────────────────────────┤
│  [ < 上一页 ]  第 1 / 3 页  [ 下一页 > ]                     │
├─────────────────────────────────────────────────────────────┤
│  已选：反欺诈图片数据集（sourceId=81 · /anti_fraud_images…） │
│                    [ 取消 ]  [ 确认使用此数据集 ]           │
└─────────────────────────────────────────────────────────────┘
```

- **数据源列**：展示父接口中的数据源 **名称**（或 `name`）+ **id**，便于区分；若列表接口已带 `sourceId`，可直接显示 `sourceId` 对应名称（需前端缓存一次数据源列表或合并请求）。
- **路径前缀**：数据集 `path` 字段，截断过长用 `Tooltip` 展示全文。
- **分页**：与父接口 `page` / `limit` 对齐；默认 `limit=10`。

## 4. 交互与状态

| 状态 | 表现 |
|------|------|
| **初始打开** | 请求数据集列表（第一页）；表格 Skeleton 或行内 Spinner。 |
| **空列表** | EmptyState：`当前没有可用数据集` + 文案引导检查父平台权限。 |
| **请求失败** | 顶部或 Modal 内 `Alert`：网络错误 / 401 未登录 / 业务 `code !== 0`。 |
| **单行选择** | 点击「选择」高亮该行；或单选 radio；底部「已选」同步更新。 |
| **确认** | 触发 `onConfirm(selection)`，向父级 `ImportPage` 传出结构化对象（见下节），**关闭 Modal**。 |
| **取消** | 关闭 Modal，不修改已上传文件列表。 |

**与下方拖拽区关系**：选择数据集 **不**等同于已上传文件；确认后可在顶栏或列表区显示 **一行摘要标签**（Badge）：

```text
已关联父平台数据集：反欺诈图片数据集  [ 清除 ]
```

便于用户理解「当前导入策略 = 父平台 S3 数据集」；清除后恢复仅 URL/本地上传。  
（若产品希望「三选一互斥」，可在确认数据集时清空 `file_upload_ids` 或反之，由产品定；设计建议 **允许并存时给出明确提示**，避免误覆盖。）

## 5. 对外数据结构（供后续对接 LS 后端）

Modal 确认时向上抛出 **一个对象**（字段名可与父接口对齐，便于 BFF 映射 S3）：

```ts
type ParentDatasetSelection = {
  /** 父平台数据源 id，对应 list[].sourceId */
  sourceId: number;
  /** 数据集 id */
  datasetId: number;
  /** 展示名 */
  datasetName: string;
  /** S3 前缀，如 /anti_fraud_images/20250923 */
  path: string;
  /** 可选：若创建存储时需要一并带上 */
  dataSetType?: string;
};
```

后续整链：由 **LS 后端** 根据 `sourceId` 拉取 TDSC 凭证 + `path` 写入 `S3ImportStorage` 并 sync；前端只负责 **选择并提交该 payload**（或先 `localStorage` 暂存至项目创建完成再打 API）。
